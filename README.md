# R&Music

Музыкальное приложение в стиле Яндекс Музыки с золото-серебряной темой.

### Веб-версия (сайт)

**Ссылка:** https://raviloper08-cell.github.io/RandMusic/

> Чтобы ссылка заработала, нужно один раз включить GitHub Pages (займёт 20 секунд):
> 1. Открой репозиторий → **Settings**
> 2. Слева выбери **Pages**
> 3. В разделе **Source** выбери **Deploy from a branch**
> 4. Branch: `main` → папка `/ (root)` → нажми **Save**
> 5. Подожди 1–2 минуты — сайт станет доступен по ссылке выше.

---

### Десктопное приложение (Electron)

1. Установи [Node.js](https://nodejs.org/)
2. Скачай репозиторий:
   ```bash
   git clone https://github.com/raviloper08-cell/RandMusic.git
   cd RandMusic
   ```
3. Установи зависимости и запусти:
   ```bash
   npm install
   npm start
   ```

### Собрать установщик
```bash
npm run build:win     # Windows (.exe)
npm run build:mac     # macOS (.dmg)
npm run build:linux   # Linux
```
