# R&Music 

Музыкальное веб-приложение, вдохновлённое Яндекс Музыкой.

### Особенности
- Тёмная тема с **золотыми** и **серебряными** акцентами
- «Золотая Волна» (аналог «Моей волны»)
- Плеер внизу
- Поиск, плейлисты, коллекция
- Возможность добавлять треки (мок)
- Полностью публичный репозиторий

### Запуск
Просто открой `index.html` в браузере или задеплой на GitHub Pages / любой хостинг.
