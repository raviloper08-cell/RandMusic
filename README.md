# R&Music

**Настоящее десктопное приложение** (не сайт) — музыкальный плеер в стиле Яндекс Музыки.

### Особенности
- Тёмная тема с **золотыми** и **серебряными** акцентами
- «Золотая Волна» (аналог «Моей волны»)
- Полноценный плеер
- Поиск, коллекция, плейлисты
- Возможность добавлять свои треки
- Работает как настоящее приложение Windows / macOS / Linux

---

### Как запустить

1. Установи [Node.js](https://nodejs.org/) (если ещё нет)
2. Скачай или клонируй репозиторий:
   ```bash
   git clone https://github.com/raviloper08-cell/RandMusic.git
   cd RandMusic
   ```
3. Установи зависимости:
   ```bash
   npm install
   ```
4. Запусти приложение:
   ```bash
   npm start
   ```

Приложение откроется в отдельном окне (не в браузере).

---

### Собрать установщик (.exe / .dmg / AppImage)

```bash
npm run build        # для текущей ОС
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

Готовые файлы появятся в папке `dist/`.
